# Интеллектуальные системы в управлении бизнесом

Материалы дисциплины. Магистратура, направление 38.04.05 «Бизнес-информатика», программа «Бизнес-аналитика», 2 курс. Осенний семестр 2026/2027 — второй семестр изучения дисциплины.

Преподаватель: Заводчикова М. Г. Очная группа БИЗ-М-2-Д-2025-1 (11 человек), заочная группа БИЗ-М-2-З.

Нагрузка: 14 часов лекций (7 лекций), 28 часов практических занятий (14 занятий), экзамен.

## Идея курса

Курс связан с магистерской диссертацией студента через **регулярное управленческое решение**, выделенное из темы исследования. Работа идёт в двух контурах: индивидуальном (своя тема — от контура управления до регламента принятия решения и оценки эффекта) и общем (прототип на учебном кейсе). Подробнее — в `concept/koncepciya-kursa.md`.

## Структура репозитория

- `concept/` — концепция курса и связь с диссертацией
- `plan-zanyatiy.md` — план лекций и практических занятий
- `lectures/` — конспекты лекций в markdown
- `seminars/` — материалы практической части
- `control/` — контроль: что готово, что предстоит сделать
